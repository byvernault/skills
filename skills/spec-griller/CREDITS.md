# Credits

The spec template — Problem Statement, Solution, User Stories, Implementation Decisions, Testing Decisions, Out of Scope, Further Notes — and the seam-sketching step that precedes it come from [Matt Pocock](https://github.com/mattpocock)'s [`to-spec`](https://github.com/mattpocock/skills) skill, reproduced word for word. The structure around it is different: `to-spec` forbids interviewing and synthesises a conversation that already happened, while this skill grills first and writes the spec from the decisions that grilling settles.

`spec-griller` does not depend on `to-spec` as a skill — it isn't part of this repo, and a hard dependency would break standalone installs — so the template is copied in rather than pointed at. This file is the attribution a dependency would otherwise have carried.
